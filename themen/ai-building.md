### Sicherheit und Rechte

- **Agenten mit Zugriff auf produktive Systeme brauchen eine Kontrollschicht (4 Quellen).** Ein Coding-Agent im Fachbereich kann ein Skript erzeugen, das ohne Review, Tests und Deployment-Kontrolle in den Tagesbetrieb gelangt. Wer externe Dienste anbindet, muss sicherstellen, dass das Modell nicht halluziniert oder Unsinn ausführt. Das gilt besonders bei Schreibzugriff auf Datenbanken [MCP erklärt](../quellen/2026/11/2026-11-09-model-context-protocol-mcp-clearly-explained-why-it-matters.md). Ein Agent, der ohne Bestätigungsabfragen überall alles darf, wird laut einem Kommentator früher oder später Dateien löschen; Löschaktionen sollten eine Rückfrage auslösen. Ob der Agent im Fall des Chicagoer Juraprofessors William Baude so lief, ist nicht belegt (Behauptung ohne Beleg). Anthropic empfiehlt für Arbeit an eigenen Dateien den Auto Mode, der Aktionen vor der Ausführung auf Risiko prüft; seine Schutzwirkung ist nicht belegt, siehe „Warnungen: Agenten mit Dateizugriff“ (Herstellerangabe) [Claude löscht Syllabus](../quellen/2026/11/2026-11-15-claude-asked-to-renumber-pages-deletes-professor-s-syllabus.md). Laut einem Sicherheitsvideo gehören alle Aktionen eines Agenten protokolliert und unbefugte Vorgänge aktiv blockiert. Als Prüffall nennt der Sprecher einen Versuch, die .env-Datei nach außen zu senden, der erkannt und gestoppt werden muss; gilt für produktive Agenten-Infrastruktur, besonders bei wertvollen Systemen (Behauptung ohne Beleg) [LLM-Backdoors](../quellen/2026/11/2026-11-16-the-new-ai-security-nightmare-undetectable-llm-backdoors.md).
- **Rechte von Agenten knapp zuschneiden (8 Quellen).** Ein Agent mit Zugriff auf Werbebudgets, Zahlungen oder Kundendaten soll nur so viele Rechte bekommen, dass der Schaden bei Kompromittierung begrenzt bleibt, etwa Read-only auf wichtigen Plattformen (Anekdote) [Agenten-Kurs](../quellen/2026/11/2026-11-13-building-ai-agents-that-actually-work-full-course.md). Auch bestandene Tests sind kein Beweis: Agenten zeigen Gefälligkeit, etwa fünf von fünf Sternen für schwache Texte, und ändern im Training Unit-Tests, statt das Problem zu lösen. ### Coding-Agenten in Organisationen steuern

- **Richtlinien nach Rolle und Werkzeugtyp schneiden.** Goldman Sachs trennt laut Bloomberg Chat-Assistenz von ausführenden Coding-Agenten. Der hauseigene Assistent mit Modellen mehrerer Anbieter bleibt für alle offen. Claude Code und GitHub sind seit Oktober auf Entwickler und Strats beschränkt. Eine frühere Einschränkung in Hongkong richtete sich nach Standort und Vertragsbedingungen, die neue richtet sich nach der Rolle. - **Für jedes Tool einen verantwortlichen Engineer benennen.** Bevor Coding-Agenten an Nicht-Entwickler gehen, sollte für jedes daraus entstehende Tool ein namentlich benannter Engineer die Verantwortung übernehmen, bevor es Produktionsdaten berührt. Das empfiehlt die Redaktion von State of AI [Goldman zieht Claude Code zurück](../quellen/2026/11/2026-11-09-goldman-sachs-is-pulling-claude-code-from-its-bankers-and-tr.md).
- **Agenten im Betrieb des Engineerings laufen lassen.** Goldman nutzt Claude weiter, aber unter Kontrolle des Engineerings. Laut Goldman halfen Anthropic-Engineers sechs Monate lang beim Bau von Agenten für Trade Accounting und Client Onboarding. Betrieben werden diese Agenten im Back Office von Goldmans Engineering (Herstellerangabe) [Goldman zieht Claude Code zurück](../quellen/2026/11/2026-11-09-goldman-sachs-is-pulling-claude-code-from-its-bankers-and-tr.md). Zum selben Muster bei Vercel siehe „Was mehrfach belegt ist“.
- **Vor dem Entzug eines Werkzeugs erfassen, wofür es genutzt wurde.** Bei Goldman waren das die Überwachung von Kundenflüssen, die Modellierung von Positionen und das Erstellen von Unterlagen. Diese Bedarfe könnte das Engineering übernehmen [Goldman zieht Claude Code zurück](../quellen/2026/11/2026-11-09-goldman-sachs-is-pulling-claude-code-from-its-bankers-and-tr.md).
- **Eine Rücknahme erklären und Ersatz nennen.** State of AI hält die Einschränkung für richtig. Die Redaktion kritisiert aber, dass der CIO im Juli das Vibe Coding von Tradern lobte und der Zugang im Oktober per Richtlinien-Update entzogen wurde, ohne dass ein Ersatz genannt wurde. Das gilt für jede Rücknahme eines zuvor beworbenen KI-Werkzeugs (Meinung der Redaktion) [Goldman zieht Claude Code zurück](../quellen/2026/11/2026-11-09-goldman-sachs-is-pulling-claude-code-from-its-bankers-and-tr.md).
- **Eine abgesicherte Umgebung bauen, statt Agenten zu entziehen.** Das Engineering kann eine Programmierumgebung mit Abstraktionen bauen, in der Agenten aus dem Fachbereich arbeiten, ohne Schaden anzurichten. ### Wirkung von Coding-Agenten messen

- **Produktivität an einer Downstream-Kennzahl messen.** Geeignet sind erledigte Issues mit Code in Produktion und die Zeit bis Merge. Funktioniert nur, wenn die eingesetzten Tools diese Marker setzen (eigene Daten) [Harvard-Review-Studie](../quellen/2026/11/2026-11-18-harvard-researchers-find-ai-coding-agents-shifted-the-bottle.md).
- **Mit einem Log der Reviewer-Änderungen den Engpass zuordnen.** Das Zwei-Kanal-Modell der Studie: Entweder verstopft reines Volumen den Reviewer-Pool, dann hilft mehr Review-Arbeitskraft, oder die Entwürfe sind schlechter, dann braucht es bessere Modelle. Ein Log der Reviewer-Änderungen zeigt, welcher Kanal dominiert und wofür Budget nötig ist; die Gewichtung der Kanäle beziffert die Studie nicht (eigene Daten) [Harvard-Review-Studie](../quellen/2026/11/2026-11-18-harvard-researchers-find-ai-coding-agents-shifted-the-bottle.md).
- **Beim Kauf von Legal-AI zuerst die Art des Outputs klären.** Erzeugt der Agent Populationsoutput, der sich per Sampling validieren lässt, oder Einzeldokumente wie Einreichungen, die direkt zu prüfen sind? Danach Downstream-Kennzahlen verlangen: Stunden bis zum freigegebenen Arbeitsprodukt, Rückläuferquote der Entwürfe, Reviewer-Zeit pro Fall. ### Integrationen und MCP verstehen

- **Drei Stufen als Prüfraster für KI-Produkte.** Ein LLM allein sagt nur Text voraus. Mit Tools greift es über einzeln verdrahtete Integrationen auf Dienste zu. Mit MCP nutzt es eine einheitliche Übersetzungsschicht zu allen Diensten [MCP erklärt](../quellen/2026/11/2026-11-09-model-context-protocol-mcp-clearly-explained-why-it-matters.md). Dass MCP ein offener Standard ist, steht unter „Was mehrfach belegt ist: Integrationen“.
- **Das MCP-Ökosystem hat vier Teile.** Der Client ist die Seite zu Nutzer und Modell, etwa Cursor, Windsurf oder Tempo. Das Protokoll ist die Zweiwegverbindung. Der Server übersetzt die Fähigkeiten eines Dienstes. Dazu kommt der Dienst selbst [MCP erklärt](../quellen/2026/11/2026-11-09-model-context-protocol-mcp-clearly-explained-why-it-matters.md).
- **Funktionen erst ausliefern, wenn auch Agenten sie nutzen können.** Bei Vercel gilt eine neue Funktion erst als releasefähig, wenn sie im Dashboard, in der CLI und über MCP verfügbar ist, damit Menschen und Agenten sie nutzen können. Gilt für B2B-Software mit API und Tooling (eigene Daten) [Vercel-COO](../quellen/2026/11/2026-11-15-how-to-get-ai-agents-to-recommend-your-business-vercel-coo.md).
- **Das Prinzip lernen, nicht nur den Standard.** Wer MCP versteht, kann sofort loslegen, sobald ein Standard final ist. Das gilt auch, wenn es am Ende nicht MCP wird [MCP erklärt](../quellen/2026/11/2026-11-09-model-context-protocol-mcp-clearly-explained-why-it-matters.md).
- **Startup-Idee für technische Gründer.** Gemeint ist ein Verzeichnis von MCP Servern mit GitHub-Code und Bereitstellung per Klick, das dem Nutzer eine eigene URL für seinen MCP Client liefert. Markttest, Wettbewerbsanalyse und Geschäftsmodell fehlen [MCP erklärt](../quellen/2026/11/2026-11-09-model-context-protocol-mcp-clearly-explained-why-it-matters.md).

- **Informationsbarrieren gelten auch für agentengebaute Tools.** Das betrifft zum Beispiel die Trennung zwischen Deal-Bankern und Tradern.
